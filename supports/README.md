# Supports du cours

Supports de « IA agentiques avec Spring AI » (M2 MIAGE IPM). Ordre des séances : CM1, TD1, TD2, CM2, TD3, TD4, TD5, CM3, TD6, CM4 (évaluation de TD, 1 h sur machine, sans slide).

| Fichier | Contenu |
|---|---|
| `cm/CM.md` | Texte des 142 slides dans l'ordre de présentation, avec les notes de l'enseignant |
| `cm/slides/*.html`, `cm/deck.json`, `cm/deck.css` | Sources du diaporama (une slide par fichier, l'ordre est dans `deck.json`) ; générées par l'éditeur de slides, à ne pas écrire à la main |
| `sujets/` | Sujets de TD1 à TD6 (version distribuée aux étudiants, suggestions acceptées) et `00-informations-communes.md` |
| `evaluation/matrice-competences.md` | Matrice de compétences, échelle de niveaux, mode d'emploi |

Limites : le classeur interactif de la matrice (formules de progrès, feuille « Synthèse ») reste dans le classeur en ligne ; les sources de référence des sujets restent les documents en ligne, `sujets/` en est l'export Markdown ; les slides de séquence et d'architecture (`seq-*`, `arch-*`) sont des schémas dont `CM.md` ne garde que les libellés.
